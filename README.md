
# 777Joya Aviator Predictor (Streamlit Web App)

This is a simple Streamlit app that predicts the next multiplier in the Aviator game based on recent multiplier history extracted from a screenshot.

## How to deploy (Free):
1. Go to https://github.com and create a new repository (e.g. aviator-predictor)
2. Upload all files from this zip into the repository
3. Go to https://share.streamlit.io
4. Click "New app" and select your GitHub repo
5. Enter `streamlit_aviator_predictor.py` as the main file
6. Click "Deploy"

Done! You will get your own free link to use the predictor from any browser.

**This app is for observation only. Not for gambling.**
